# Classical ciphers

- Document: c07 (course)
- Source: Written for this project from the topics of the CoSc4035 Computer Security course slides (Jimma University), Chapter 3, part 1
- Licence: CC BY 4.0

All classical encryption techniques are built from two operations. Substitution replaces each element of the plaintext (a letter, a bit, or a group of them) with another element. Transposition, also called permutation, keeps the elements but changes their order.

The Caesar cipher is the oldest and simplest known substitution cipher, used by Julius Caesar. Each letter is replaced by the letter three places further down the alphabet, wrapping around so that Z becomes C. If the letters are numbered from 0 to 25, encryption is C = (p + 3) mod 26. The general version allows any shift k from 1 to 25: C = (p + k) mod 26, and decryption is p = (C - k) mod 26. For example, with a shift of 3, "are you ready" becomes "DUH BRX UHDGB". The Caesar cipher is far from secure. The algorithm is known, there are only 25 possible keys, and the language of the plaintext is usually easy to recognise, so an attacker can simply try every key.

In a monoalphabetic cipher, the alphabet is shuffled at random instead of shifted, so the key is a list of 26 letters. This gives far more keys, but the cipher can still be broken because human languages are redundant. In English the letter E appears much more often than any other, T, A, O and I come next, and Z, J, Q and X are rare. Counting how often each letter appears in the ciphertext reveals the substitutions.

The Playfair cipher encrypts pairs of letters instead of single letters. It uses a 5 x 5 grid filled with a keyword followed by the remaining letters of the alphabet, with I and J sharing one cell. It was invented by Charles Wheatstone in 1854 but is named after Lord Playfair, who promoted its use, and it was used in both world wars.

The Vigenere cipher is the best-known polyalphabetic cipher. It uses all 26 Caesar ciphers. The keyword is written repeatedly above the plaintext, and each key letter decides which Caesar shift is applied to the plaintext letter beneath it.
