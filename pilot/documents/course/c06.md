# Security plans and operating system hardening

- Document: c06 (course)
- Source: Written for this project from the topics of the CoSc4035 Computer Security course slides (Jimma University), Chapter 2
- Licence: CC BY 4.0

Technical measures alone are not enough; an organisation also needs administrative controls. The main one is a security plan, a document that describes the current state of security of a computing system and how it will be improved. A security plan must address seven issues:
1. Policy: the goals of the security effort and how willing the people involved are to work towards them.
2. Current state: the status of security when the plan is written.
3. Requirements: the ways recommended to meet the security goals.
4. Recommended controls: which controls deal with which weaknesses found in the policy and requirements.
5. Accountability: the person responsible for each security task.
6. Timetable: when each security function will be carried out.
7. Continuing attention: how the plan itself will be reviewed and updated over time.

Planning matters for operating systems too. A study of targeted cyber intrusions investigated in 2009 found that more than 70% of them could have been prevented. The four most effective measures were:
- patching the operating system and applications with automatic updates;
- patching third-party applications;
- giving administrator privileges only to the users who need them;
- allowing only approved applications to run (application white-listing).

A new system can be compromised while it is being installed, before the latest patches are applied, so setting up a new system should follow a plan. The first critical step is to harden the base operating system:
1. Install the operating system and apply all patches.
2. Harden and configure it to meet the security needs identified for that system.
3. Add extra security controls and set them up, for example anti-virus software, a host-based firewall and an intrusion detection system.
4. Test the security of the base system to make sure that these steps meet its needs.
