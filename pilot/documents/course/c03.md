# Types of malware

- Document: c03 (course)
- Source: Written for this project from the topics of the CoSc4035 Computer Security course slides (Jimma University), Chapter 2
- Licence: CC BY 4.0

Malicious code, or malware, is any program or script written to harm a computer system or network, usually by creating or exploiting a vulnerability. The main types covered in this course are viruses, worms, Trojan horses, logic bombs, spyware and adware.

A virus copies itself into other programs stored on a computer and spreads from there. Most viruses need a user to start them, for example by opening an infected program, and some are written to activate on a particular date or time.

A worm is an independent program. Unlike a virus, it does not need a host program: it spreads by itself by exploiting weaknesses in networks, copying itself from one computer to the next. After the first infection, no user action is needed. Worms usually slow networks down and often cause denial of service.

A Trojan horse looks like something the user wants, such as an online game, but carries out harmful actions in the background. It runs with the privileges of the user who started it.

A logic bomb stays inactive until a trigger event occurs. Triggers can be a date, a time, another program starting, or the deletion of a particular user account. When the trigger happens, the malicious code runs and damages the computer.

Spyware collects information about what a user does on the computer, for example through activity trackers and keystroke logging, and it often changes security settings so that it is not stopped. Adware shows pop-up advertisements to earn money for its authors and may track the websites a user visits in order to choose the adverts.

A virus hoax is not a program at all. The attacker sends e-mails that pretend to come from a well-known antivirus company, warning of a new virus and telling people to delete a certain file. The file is actually a normal part of the operating system, so people who follow the advice damage their own computers, and some of them forward the warning to their friends and colleagues.
